# SysBoard

A system info dashboard built with [Neutralinojs](https://neutralino.js.org)
as part of GSoC 2026 exploration.

## Features
- Live OS, memory, kernel info via Neutralinojs native APIs
- Folder dialog, desktop notification, shell command execution
- Lightweight — no Electron, no Node.js runtime

## Run locally
```bash
npm i -g @neutralinojs/neu
neu run
```

## Built with
- Neutralinojs v6.5.0
- Plain HTML/CSS/JS
